Sobre o curso

Da primeira página ao sistema completo

A formação apresenta os fundamentos do desenvolvimento web em uma sequência progressiva, unindo front-end, back-end, banco de dados, autenticação e integração por API.

Aprendizado contínuoCada semana amplia o projeto iniciado na etapa anterior.
Prática orientadaOs conceitos são acompanhados por exemplos e sugestões de aplicação.
Visão completaO aluno entende o caminho percorrido pelos dados em uma aplicação web.

Programa de estudos

Oito semanas, uma evolução

Os materiais abaixo servem como base de consulta durante o curso. Não substituem a orientação em sala, mas ajudam a revisar conceitos e acompanhar o desenvolvimento do projeto.

01

Fundamentos da web

HTML, CSS e introdução ao JavaScript

Estrutura, conteúdo, aparência e o papel de cada tecnologia.

Estudar esta semana
02

Lógica e interação

JavaScript e DOM

Variáveis, operadores, estruturas básicas, seleção de elementos e eventos.

Estudar esta semana
03

Versionamento e back-end

Git, GitHub e introdução ao PHP

Histórico do código, repositórios remotos e ambiente local.

Estudar esta semana
04

Programação no servidor

Fundamentos do PHP e formulários

Dados, decisões, repetições, funções e processamento de formulários.

Estudar esta semana
05

Dados e persistência

GET, POST, sessões e MySQL

Recebimento, validação, sessão e organização dos dados.

Estudar esta semana
06

Aplicação dinâmica

PHP, MySQL e CRUD

Cadastro, consulta, atualização e exclusão de registros.

Estudar esta semana
07

Acesso protegido

CRUD e autenticação

Usuários, senhas protegidas, sessões e controle de acesso.

Estudar esta semana
08

Integração

API REST e projeto integrador

Endpoints, métodos HTTP, JSON, testes e entrega final.

Estudar esta semana

Projeto integrador

Um único projeto crescendo junto com o aprendizado

Ao longo das semanas, a turma constrói uma aplicação web completa: começa pela interface e pelas interações com JavaScript e DOM, passa pelo versionamento e pelo PHP, incorpora banco de dados e autenticação e termina com uma integração por API.

  1. 1
    Interface e interação

    HTML e CSS organizam a página; JavaScript e DOM acrescentam comportamentos.

  2. 2
    Regras e dados

    PHP, formulários e MySQL tornam a aplicação dinâmica.

  3. 3
    Sistema completo

    CRUD, autenticação e API finalizam a solução.
