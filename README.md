# Curso de Desenvolvimento Web Full Stack

Site estático de apresentação e apoio ao curso de extensão em Desenvolvimento Web Full Stack.

## Conteúdo

- apresentação do curso;
- carga horária de 40 horas;
- programa organizado em oito semanas;
- materiais básicos de consulta;
- evolução do projeto integrador.

O site não possui cadastro, login, banco de dados, vídeos, questionários ou coleta de informações pessoais.

## Estrutura

```text
index.html            Página principal
assets/               Identidade visual e imagem principal
conteudos/            Materiais das oito semanas
```

## Abrir localmente

Abra o arquivo `index.html` em qualquer navegador. Não é necessário instalar PHP, MySQL, XAMPP ou outras dependências.

## Publicar no GitHub Pages

1. Abra as configurações do repositório no GitHub.
2. Entre em **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde o endereço público ser criado.

## Privacidade

Nenhum dado de aluno é solicitado ou armazenado. As atividades, entregas e acompanhamento da turma devem ser realizados no ambiente educacional escolhido pela instituição.
