Dados e operações

Variáveis, tipos e operadores

Variáveis armazenam valores que serão utilizados pelo programa. Em JavaScript moderno, const é usada quando a referência não será reatribuída e let quando o valor poderá mudar.

String

Texto, como nome, categoria ou mensagem.

Number

Números inteiros ou decimais usados em cálculos.

Boolean

Representa apenas verdadeiro ou falso.

Array

Agrupa diversos valores em uma lista ordenada.

const curso = "Full Stack";
let semanasConcluidas = 2;
const totalSemanas = 8;
const progresso = (semanasConcluidas / totalSemanas) * 100;

console.log(`Progresso: ${progresso}%`);

Fluxo do programa

Condições

Uma estrutura condicional escolhe qual trecho executar de acordo com uma comparação.

const nota = 8;

if (nota >= 7) {
    console.log("Atividade concluída");
} else {
    console.log("Revise o conteúdo e tente novamente");
}

Operadores como ===, >, <, >= e <= produzem resultados verdadeiros ou falsos.

Automação

Estruturas de repetição

Laços evitam escrever a mesma instrução diversas vezes. O for é útil quando existe uma quantidade conhecida de repetições.

const tecnologias = ["HTML", "CSS", "JavaScript"];

for (const tecnologia of tecnologias) {
    console.log(tecnologia);
}

Organização

Funções reutilizáveis

Funções agrupam instruções relacionadas. Elas podem receber parâmetros e devolver um resultado.

function calcularProgresso(concluidas, total) {
    return Math.round((concluidas / total) * 100);
}

const resultado = calcularProgresso(3, 8);
console.log(`${resultado}%`);
Importante: pratique cada estrutura separadamente e acompanhe os resultados pelo console do navegador.

Página interativa

O que é o DOM

Quando o navegador lê o HTML, ele cria uma representação organizada do documento chamada DOM, sigla para Document Object Model. Cada título, parágrafo, botão ou campo passa a ser um objeto que o JavaScript pode localizar e modificar.

O método document.querySelector() procura o primeiro elemento que corresponde a um seletor CSS. Por isso, a mesma forma de identificar tags, classes e IDs aprendida no CSS também é usada pelo JavaScript.

const titulo = document.querySelector('h1');
const cartao = document.querySelector('.cartao');
const mensagem = document.querySelector('#mensagem');

titulo.textContent = 'Projeto atualizado';
cartao.classList.add('destaque');
mensagem.setAttribute('aria-live', 'polite');
textContent

Lê ou substitui o conteúdo textual de um elemento.

classList

Adiciona, remove ou alterna classes CSS.

setAttribute()

Define ou modifica um atributo HTML.

value

Acessa o valor atual de campos de formulário.

Antes de alterar um elemento, confirme que ele foi encontrado. Um seletor incorreto pode retornar null, indicando que nenhum elemento correspondente existe na página.

Ações da pessoa usuária

Eventos e addEventListener()

Um evento informa que algo aconteceu na página. O JavaScript pode aguardar esse acontecimento e executar uma função em resposta. Entre os eventos mais comuns estão click, input e submit.

const botao = document.querySelector('#mostrar-mensagem');
const mensagem = document.querySelector('#mensagem');

botao.addEventListener('click', function () {
    mensagem.textContent = 'Conteúdo atualizado com JavaScript!';
    mensagem.classList.toggle('destaque');
});

No exemplo, o botão é selecionado pelo ID. Quando ocorre o clique, a função altera o texto e alterna uma classe. O HTML define os elementos, o CSS define a aparência da classe e o JavaScript coordena a interação.

Eventos em formulários

const formulario = document.querySelector('#cadastro');
const nome = document.querySelector('#nome');

formulario.addEventListener('submit', function (evento) {
    evento.preventDefault();

    if (nome.value.trim() === '') {
        alert('Informe seu nome.');
        return;
    }

    console.log(`Cadastro enviado por ${nome.value}`);
});

O evento submit acontece quando o formulário é enviado. preventDefault() interrompe temporariamente o comportamento padrão para que os dados possam ser conferidos. Essa validação melhora a experiência, mas aplicações reais também precisam validar os dados no servidor.

Prática sugerida

Adicione interação ao projeto

  1. Crie no HTML um campo de texto, um botão e uma área de mensagem.
  2. Selecione os três elementos com querySelector().
  3. Use o evento input para acompanhar o valor digitado.
  4. Use o evento click para atualizar o texto da mensagem e alternar uma classe CSS.
  5. Inclua um formulário e trate o evento submit, impedindo o envio quando o campo estiver vazio.
  6. Acompanhe os valores pelo console e teste seletores incorretos para compreender o retorno null.
