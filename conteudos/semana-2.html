Dados e operações

Variáveis, tipos e operadores

Variáveis armazenam valores que serão utilizados pelo programa. Em JavaScript moderno, const é usada quando a referência não será reatribuída e let quando o valor poderá mudar.

String

Texto, como nome, categoria ou mensagem.

Number

Números inteiros ou decimais usados em cálculos.

Boolean

Representa apenas verdadeiro ou falso.

Array

Agrupa diversos valores em uma lista ordenada.

const curso = "Full Stack";
let semanasConcluidas = 2;
const totalSemanas = 8;
const progresso = (semanasConcluidas / totalSemanas) * 100;

console.log(`Progresso: ${progresso}%`);

Fluxo do programa

Condições

Uma estrutura condicional escolhe qual trecho executar de acordo com uma comparação.

const nota = 8;

if (nota >= 7) {
    console.log("Atividade concluída");
} else {
    console.log("Revise o conteúdo e tente novamente");
}

Operadores como ===, >, <, >= e <= produzem resultados verdadeiros ou falsos.

Automação

Estruturas de repetição

Laços evitam escrever a mesma instrução diversas vezes. O for é útil quando existe uma quantidade conhecida de repetições.

const tecnologias = ["HTML", "CSS", "JavaScript"];

for (const tecnologia of tecnologias) {
    console.log(tecnologia);
}

Organização

Funções reutilizáveis

Funções agrupam instruções relacionadas. Elas podem receber parâmetros e devolver um resultado.

function calcularProgresso(concluidas, total) {
    return Math.round((concluidas / total) * 100);
}

const resultado = calcularProgresso(3, 8);
console.log(`${resultado}%`);
Importante: pratique cada estrutura separadamente e acompanhe os resultados pelo console do navegador.
