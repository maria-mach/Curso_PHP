Dados e operações

Variáveis, tipos e cálculos

Uma variável associa um nome a um valor. Em JavaScript moderno, const é a escolha comum quando a variável não receberá outro valor. let é usada quando haverá reatribuição durante a execução.

const totalSemanas = 8;
let semanasConcluidas = 2;

semanasConcluidas = 3; // permitido com let
// totalSemanas = 10;  // causaria erro

const não torna todos os valores imutáveis. Ela impede que a variável seja apontada para outro valor. Para os exemplos iniciais, a diferença principal é simples: use const quando não houver reatribuição e let quando o valor precisar mudar.

Tipos e estruturas

String

Representa texto. Exemplo: "Maria".

Number

Representa números inteiros ou decimais. Exemplo: 8.

Boolean

Representa apenas true ou false.

Array

Organiza uma lista ordenada, como ["HTML", "CSS"].

Dois valores podem formar um percentual

Para calcular o progresso, divida a quantidade concluída pelo total e multiplique por 100. Se 2 de 8 semanas foram concluídas, 2 / 8 resulta em 0.25. Multiplicar por 100 transforma esse valor em 25.

const concluidas = 2;
const total = 8;
const progresso = (concluidas / total) * 100;

console.log(`Progresso: ${progresso}%`); // 25%

Fluxo do programa

Condições e repetições

Uma condição permite escolher qual bloco será executado. A expressão dentro de if é avaliada como verdadeira ou falsa. Quando ela é verdadeira, o primeiro bloco executa. Caso contrário, o programa segue para else.

const nota = 8;

if (nota >= 7) {
    console.log("Atividade concluída");
} else {
    console.log("Revise o conteúdo");
}

Nesse caso, 8 >= 7 é verdadeiro. Portanto, o bloco de if executa e o bloco de else é ignorado. Operadores como ===, >, <, >= e <= produzem resultados booleanos.

Percorrendo uma lista com for...of

Quando os dados estão em um array, for...of percorre cada valor, um por vez. A variável declarada no laço recebe o item atual a cada repetição.

const tecnologias = ["HTML", "CSS", "JavaScript"];

for (const tecnologia of tecnologias) {
    console.log(tecnologia);
}

O console exibirá três mensagens, respeitando a ordem do array. O laço não apaga nem transforma os valores. Ele apenas permite executar uma instrução para cada item.

Organização

Funções, parâmetros e retorno

Uma função agrupa instruções relacionadas e pode ser chamada sempre que aquela tarefa for necessária. Os parâmetros recebem dados na chamada. A palavra return encerra a execução da função e devolve um resultado para quem a chamou.

function calcularProgresso(concluidas, total) {
    const percentual = (concluidas / total) * 100;
    return Math.round(percentual);
}

const resultado = calcularProgresso(3, 8);
console.log(`${resultado}%`);

Sem return, a função ainda poderia executar ações, como escrever no console, mas não entregaria o percentual para a variável resultado. Instruções colocadas depois de um return executado não são alcançadas.

Leitura do exemplo: os valores 3 e 8 entram pelos parâmetros, o cálculo acontece dentro da função e o resultado arredondado volta para o ponto da chamada.

Página interativa

JavaScript e a representação da página

Quando o navegador interpreta o HTML, ele cria o DOM, sigla para Document Object Model. Títulos, parágrafos, campos e botões passam a ser objetos que o JavaScript pode localizar, consultar e modificar.

Seleção com querySelector()

document.querySelector() recebe um seletor CSS e retorna o primeiro elemento correspondente. O sinal # procura um ID, o ponto procura uma classe e o nome da tag procura um elemento HTML. Se não existir correspondência, o retorno será null.

const mensagem = document.querySelector("#mensagem");
const primeiroCartao = document.querySelector(".cartao");
const titulo = document.querySelector("h1");

if (mensagem !== null) {
    console.log("Elemento encontrado");
}

Conteúdo, classes, atributos e campos

textContent

Lê ou substitui o texto presente no elemento.

classList

Adiciona, remove ou alterna classes CSS.

setAttribute()

Define ou altera um atributo HTML.

value

Lê ou altera o valor atual de um campo.

mensagem.textContent = "Olá!";
mensagem.classList.add("destaque");
mensagem.setAttribute("aria-live", "polite");

const nome = document.querySelector("#nome");
console.log(nome.value);

textContent altera o texto. Ele não substitui o seletor nem cria um elemento novo. Para evitar erros, o código deve confirmar que o elemento foi encontrado antes de tentar modificá-lo.

Ações da pessoa usuária

Eventos e addEventListener()

Eventos representam acontecimentos na interface. addEventListener() associa uma função a um evento e mantém as responsabilidades organizadas.

click

Acontece quando a pessoa clica em um elemento, como um botão.

input

Acontece quando o valor de um campo é alterado durante a digitação.

submit

Acontece quando um formulário é enviado.

Função ouvinte

É executada quando o evento associado acontece.

const botao = document.querySelector("#destacar");
const mensagem = document.querySelector("#mensagem");

botao.addEventListener("click", function () {
    mensagem.classList.toggle("destaque");
});

Controle do envio com preventDefault()

O comportamento padrão de um formulário é enviar os dados e navegar ou recarregar a página. Ao tratar submit, evento.preventDefault() interrompe temporariamente essa ação. Assim, o JavaScript pode conferir os dados e apresentar uma orientação antes de prosseguir.

formulario.addEventListener("submit", function (evento) {
    evento.preventDefault();

    if (nome.value.trim() === "") {
        mensagem.textContent = "Informe seu nome.";
        return;
    }

    mensagem.textContent = `Olá, ${nome.value}!`;
});
Validação em duas etapas: a conferência no navegador melhora a experiência, mas não protege sozinha uma aplicação. Quando houver servidor, os dados também deverão ser validados no back-end.
