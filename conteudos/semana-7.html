Armazenamento seguro

Nunca salve senhas em texto puro

O banco deve armazenar somente o hash produzido por password_hash(). O valor original não deve ser recuperável.

<?php
$hash = password_hash($senha, PASSWORD_DEFAULT);

$stmt = $pdo->prepare(
    'INSERT INTO usuarios (nome, usuario, senha_hash) VALUES (?, ?, ?)'
);
$stmt->execute([$nome, $usuario, $hash]);

Verificação

Processo de login

O sistema localiza o usuário e compara a senha informada com o hash armazenado.

<?php
$stmt = $pdo->prepare(
    'SELECT id, nome, senha_hash, perfil FROM usuarios WHERE usuario = ?'
);
$stmt->execute([$usuario]);
$registro = $stmt->fetch();

if ($registro && password_verify($senha, $registro['senha_hash'])) {
    session_regenerate_id(true);
    $_SESSION['usuario'] = [
        'id' => $registro['id'],
        'nome' => $registro['nome'],
        'perfil' => $registro['perfil']
    ];
}

Páginas protegidas

Controle de acesso

<?php
session_start();

if (!isset($_SESSION['usuario'])) {
    header('Location: login.php');
    exit;
}

if ($_SESSION['usuario']['perfil'] !== 'professor') {
    http_response_code(403);
    exit('Acesso não autorizado.');
}
Privacidade: colete somente os dados necessários, encerre sessões corretamente e utilize HTTPS em produção.

Fluxo seguro

Do cadastro à saída

  1. No cadastro, valide nome, usuário e senha e impeça usuários duplicados.
  2. Transforme a senha com password_hash() antes de gravá-la.
  3. No login, localize o registro pelo usuário e compare com password_verify().
  4. Após o sucesso, regenere o identificador da sessão e armazene somente os dados necessários.
  5. Em toda página protegida, verifique autenticação e permissão antes de executar ações.
  6. Na saída, limpe os dados e destrua a sessão.
<?php
session_start();
$_SESSION = [];
session_destroy();

header('Location: login.php');
exit;

Uma mensagem genérica como “usuário ou senha inválidos” evita revelar qual parte estava correta. Limites de tentativas, HTTPS e cookies de sessão configurados com segurança aumentam a proteção em produção.

Revise: diferencie autenticação de autorização, explique por que hashes não são senhas criptografadas e descreva o papel da sessão no controle de acesso.
