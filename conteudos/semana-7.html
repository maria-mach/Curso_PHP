Armazenamento seguro

Nunca salve senhas em texto puro

O banco deve armazenar somente o hash produzido por password_hash(). O valor original não deve ser recuperável.

<?php
$hash = password_hash($senha, PASSWORD_DEFAULT);

$stmt = $pdo->prepare(
    'INSERT INTO usuarios (nome, usuario, senha_hash) VALUES (?, ?, ?)'
);
$stmt->execute([$nome, $usuario, $hash]);

Verificação

Processo de login

O sistema localiza o usuário e compara a senha informada com o hash armazenado.

<?php
$stmt = $pdo->prepare(
    'SELECT id, nome, senha_hash, perfil FROM usuarios WHERE usuario = ?'
);
$stmt->execute([$usuario]);
$registro = $stmt->fetch();

if ($registro && password_verify($senha, $registro['senha_hash'])) {
    session_regenerate_id(true);
    $_SESSION['usuario'] = [
        'id' => $registro['id'],
        'nome' => $registro['nome'],
        'perfil' => $registro['perfil']
    ];
}

Páginas protegidas

Controle de acesso

<?php
session_start();

if (!isset($_SESSION['usuario'])) {
    header('Location: login.php');
    exit;
}

if ($_SESSION['usuario']['perfil'] !== 'professor') {
    http_response_code(403);
    exit('Acesso não autorizado.');
}
