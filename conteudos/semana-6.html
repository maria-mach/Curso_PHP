PHP, MySQL e CRUD

Conecte o back-end ao banco de dados e implemente as quatro operações fundamentais de uma aplicação.

Operações

O que significa CRUD

Create

Criar um novo registro com INSERT.

Read

Consultar registros com SELECT.

Update

Atualizar um registro com UPDATE.

Delete

Excluir um registro com DELETE.

PDO

Conexão entre PHP e MySQL

PDO oferece uma interface consistente para conexão e consultas. Erros devem gerar exceções durante o desenvolvimento.

<?php
$pdo = new PDO(
    'mysql:host=localhost;dbname=meu_projeto;charset=utf8mb4',
    'root',
    '',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

Em produção, credenciais devem ficar em um arquivo de configuração que não seja publicado no repositório.

Aplicação

Cadastro e consulta

<?php
$stmt = $pdo->prepare(
    'INSERT INTO tecnologias (nome, categoria) VALUES (?, ?)'
);
$stmt->execute([$nome, $categoria]);

$lista = $pdo->query(
    'SELECT id, nome, categoria FROM tecnologias ORDER BY nome'
)->fetchAll(PDO::FETCH_ASSOC);

Atualização e exclusão

<?php
$stmt = $pdo->prepare(
    'UPDATE tecnologias SET nome = ?, categoria = ? WHERE id = ?'
);
$stmt->execute([$nome, $categoria, $id]);

$stmt = $pdo->prepare('DELETE FROM tecnologias WHERE id = ?');
$stmt->execute([$id]);

Proteção

Consultas preparadas

Valores recebidos nunca devem ser concatenados diretamente ao SQL. Consultas preparadas separam o comando dos dados e ajudam a prevenir injeção de SQL.

Antes de alterar ou excluir: valide o identificador, confirme se o registro existe e verifique se o usuário possui autorização.

Prática sugerida

Implemente o CRUD do projeto

Crie páginas para cadastrar, listar, editar e excluir os registros da tabela definida na semana anterior. Use PDO, consultas preparadas e mensagens claras de sucesso ou erro.
