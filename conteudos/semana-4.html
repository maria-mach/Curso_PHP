Fundamentos do PHP e formulários

Utilize variáveis, decisões, repetições, arrays e funções para processar informações enviadas por formulários.

Nesta páginaLinguagemArraysFunçõesFormuláriosPrática

Fundamentos

Variáveis e estruturas de controle

Em PHP, variáveis começam com $. A linguagem oferece condições e repetições semelhantes às encontradas em JavaScript.

<?php
$nome = 'Maria';
$nota = 8.5;

if ($nota >= 7) {
    echo "$nome atingiu o resultado esperado.";
} else {
    echo "$nome deve revisar o conteúdo.";
}

Coleções

Arrays e repetição

Arrays armazenam diversos valores. Com foreach, cada item pode ser processado sem repetir manualmente as instruções.

<?php
$tecnologias = ['HTML', 'CSS', 'JavaScript', 'PHP'];

foreach ($tecnologias as $tecnologia) {
    echo "<li>" . htmlspecialchars($tecnologia) . "</li>";
}

Reutilização

Funções

Uma função reúne uma responsabilidade específica e pode ser utilizada diversas vezes.

<?php
function calcularProgresso(int $concluidas, int $total): int {
    return (int) round(($concluidas / $total) * 100);
}

echo calcularProgresso(4, 8) . '%';

Entrada de dados

HTML e PHP trabalhando juntos

O atributo action indica quem processará o formulário, enquanto method determina como os dados serão enviados.

<form method="post" action="processar.php">
    <label for="nome">Nome</label>
    <input id="nome" name="nome" required>
    <button type="submit">Enviar</button>
</form>
<?php
$nome = trim($_POST['nome'] ?? '');

if ($nome === '') {
    exit('Informe o nome.');
}

echo 'Olá, ' . htmlspecialchars($nome);
Segurança básica: nunca confie automaticamente em dados recebidos. Valide a entrada e use htmlspecialchars() antes de apresentar textos no HTML.
